# Voix — crédits

Les répliques sont générées hors ligne avec [Piper](https://github.com/rhasspy/piper) (synthèse vocale neuronale libre)
par `tools/gen_voices.py`, puis modifiées (hauteur, débit, effets radio / archive / télé / revenant).

| Voix Piper | Données d'entraînement | Licence des données |
|---|---|---|
| fr_FR-tom-medium | https://git.bksp.space/Tjiho/French-tts-model-piper | AGPLv3 |
| fr_FR-upmc-medium (Pierre, Jessica) | https://github.com/marytts/upmc-pierre-data | CC BY-SA 4.0 |
| fr_FR-gilles-low | https://www.kaggle.com/datasets/bryanpark/french-single-speaker-speech-dataset | CC0 |
| fr_FR-siwis-medium | https://datashare.is.ed.ac.uk/handle/10283/2353 | CC BY 4.0 |

Ces voix sont synthétiques : elles n'imitent pas la voix réelle des personnalités parodiées.
